## 지원 파일 형식
- PDF (.pdf) ← 권장
- 텍스트 (.txt)
- 마크다운 (.md)

## 업로드 방법
파일을 각 폴더에 넣은 후:

```bash
export PATH="/Users/wit/.nvm/versions/node/v24.16.0/bin:$PATH"
node scripts/upload-all-rag-files.mjs 여기에_GEMINI_API_KEY
```

## 주의사항
- Gemini 무료 File API는 **48시간 후 자동 삭제**
- 행사 전날 재업로드 필요
- 파일 크기 제한: 20MB 이하 권장
